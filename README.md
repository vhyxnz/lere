# Lere

A private, installable offline music player for audio files stored on your device.

## Run it

Open `index.html` directly in a modern browser. No installation or build step is needed.

- Uploaded audio plays locally and works offline.
- Recommendations are generated only from the songs in the current library.
- Local files are saved in the browser on this device and never uploaded anywhere.
- When served from localhost or HTTPS, the app can be installed as a PWA and its interface works offline.

For stricter browsers, serve the folder locally with any static web server and open its local URL.
